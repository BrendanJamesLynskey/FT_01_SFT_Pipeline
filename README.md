# FT 01 — Supervised Fine-Tuning Pipeline

A deep-dive presentation covering the full SFT pipeline: why fine-tuning outperforms prompting for capability and style transfer, instruction and conversation dataset construction, chat-template formats (ChatML, Llama-3, Qwen), loss masking to train only on assistant tokens, sample packing for throughput, framework choices (Axolotl, TRL SFTTrainer, Unsloth, torchtune), evaluation with perplexity and downstream suites, and practical VRAM budgeting for single- and multi-GPU runs.
